# План питания

Мобильное веб-приложение для плана питания на двоих: меню на сегодня, редактор меню, списки покупок с переносом остатков, план готовки на неделю.

Данные хранятся только в браузере (localStorage). Резервная копия — «Настройки → Экспорт JSON».

## Как устроено

- Меню — шаблон из 7 дней для каждого человека; цикл 28 дней (4 недели) от даты старта (воскресенье — закупка и готовка).
- Закупки считаются из меню: сумма за неделю → вычесть остаток → округлить вверх до шага упаковки. Излишек переходит в остаток следующей недели. Бакалея покупается раз в цикл.
- Исходные данные — `src/data/seed.ts` (из таблицы «План питания на двоих»). Тесты `src/domain/plan.test.ts` сверяют расчёт с листами таблицы.

## Разработка

```bash
npm install
npm run dev
npm test
```

Пуш в `main` собирает и публикует сайт на GitHub Pages (`.github/workflows/deploy.yml`).
